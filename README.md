# Sai Harsha — Personal Portfolio Website 🌐

> Modern, responsive developer portfolio showcasing full-stack systems, mobile tooling, and AI vision architectures.

**Live Deployment:** [allikasaiharsha-portfolio.vercel.app](https://allikasaiharsha-portfolio.vercel.app/)

---

## 🎨 Design Philosophy & Features

- **Layered Systems Concept:** Explores applications through Interface (Mobile/Web), Intelligence (Multimodal AI), and Infrastructure (Cloud/DB).
- **Responsive & Accessible:** Custom CSS architecture with semantic HTML and smooth interactions.
- **Micro-Interactions:** Custom SVG iconography, animated isometric system diagrams, and interactive tabs.

## 🛠️ Built With

- **HTML5 & Modern CSS:** CSS Custom Properties, Flexbox, CSS Grid
- **JavaScript (ES6+):** Tabbed interactions and dynamic UI states
- **Hosting & CI/CD:** Vercel
