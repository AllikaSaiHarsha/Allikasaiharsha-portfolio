---

## 🎨 Design Philosophy & Features

- **Layered Systems Concept:** Explores applications through Interface (Mobile/Web), Intelligence (Multimodal AI), and Infrastructure (Cloud/DB).
- **Responsive & Accessible:** Custom CSS architecture with semantic HTML, fluid typography, and smooth interactions.
- **Interactive Micro-Interactions:** Isometric system art, interactive architecture tabs, and theme toggling.

---

## 🛠️ Built With

- **HTML5 & Modern CSS:** CSS Custom Properties, Flexbox, and CSS Grid
- **JavaScript (ES6+):** Tabbed interactions, animations, and dynamic state
- **Hosting & CI/CD:** Vercel

---

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/AllikaSaiHarsha/Allikasaiharsha-portfolio.git

# Navigate to the project directory
cd Allikasaiharsha-portfolio

# Open index.html in your browser or run with a local server
npx serve .
```
